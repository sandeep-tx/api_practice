03 / REFERENCE

API Reference

Copy these endpoints into Postman or use them in Playwright's request fixture.

API BASE URLhttp://127.0.0.1:5000

CRUD endpoints

GET/api/itemsList all records
GET/api/items/{id}Get one record
POST/api/itemsCreate record (201)
PUT/api/items/{id}Replace record
PATCH/api/items/{id}Partial update
DELETE/api/items/{id}Delete record
POST/api/items/resetClear all records

Authorization endpoints

POST/api/auth/otp/sendGenerate OTP + session_id
POST/api/auth/otp/getDecrypt OTP using session_id
POST/api/auth/otp/verifyVerify OTP and return token
POST/api/auth/loginEmail/password login
GET/api/auth/meProtected; Bearer token required
POST/api/auth/logoutInvalidate current token

Example request bodies

Create item — POST /api/items

{
  "name": "Wireless keyboard",
  "category": "Accessories",
  "quantity": 2,
  "price": 1299.00
}

Send OTP — POST /api/auth/otp/send

{ "mobile": "9876543210" }

Get OTP — POST /api/auth/otp/get

{ "session_id": "paste-session-id-here" }

Verify OTP — POST /api/auth/otp/verify

{ "session_id": "paste-session-id-here", "otp": "123456" }

API login — POST /api/auth/login

{ "email": "learner@example.com", "password": "Practice@123" }
Deployment note: Netlify hosts the static UI, not this Flask server. Deploy the Flask API separately (for example, Render or Railway), then set API_BASE_URL in frontend/config.js to the deployed API URL. This practice app uses in-memory data, so records and tokens reset on restart. Do not use real personal data or deploy as a production auth service.
